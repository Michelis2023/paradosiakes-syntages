## 📖 Περιγραφή

Μια διαδραστική συλλογή **αυθεντικών ελληνικών συνταγών** που διατηρούν τη γεύση και την παράδοση της ελληνικής κουζίνας. Το project αυτό αποτελεί ψηφιακό βιβλίο μαγειρικής με λεπτομερείς οδηγίες, φωτογραφίες και εύκολη πλοήγηση.

### ✨ Χαρακτηριστικά

- 🔍 **Αναζήτηση συνταγών** ανά όνομα ή υλικό
- 🏷️ **Φιλτράρισμα** ανά κατηγορία (Κυρίως Πιάτα, Σαλάτες, Γλυκά, Εορταστικά)
- 📱 **Responsive design** - Λειτουργεί τέλεια σε κινητά, tablet και desktop
- 🎨 **Σύγχρονη διεπαφή** με καθαρό και φιλικό σχεδιασμό
- 📬 **Φόρμα επικοινωνίας** για υποβολή νέων συνταγών
- 🌐 **SEO optimized** για καλύτερη ανακαλυψιμότητα στο Google
- ⚡ **Γρήγορη φόρτωση** χωρίς εξωτερικές βιβλιοθήκες

## 🛠️ Εγκατάσταση και Τοπική Χρήση

### Προαπαιτούμενα

Δεν χρειάζονται ιδιαίτερες απαιτήσεις! Απλά ένα πρόγραμμα περιήγησης (browser).

### Βήματα

1. **Clone το repository:**

```bash
git clone https://github.com/Michelis2023/paradosiakes-syntages.git
```

2. **Μπείτε στον φάκελο:**

```bash
cd paradosiakes-syntages
```

3. **Ανοίξτε το αρχείο `index.html` στον browser σας:**

- Κάντε διπλό κλικ στο αρχείο, ή
- Χρησιμοποιήστε έναν local server όπως:

```bash
# Python 3
python -m http.server 8000

# Node.js (με npx)
npx http-server
```

4. **Ανοίξτε στον browser:**

```
http://localhost:8000
```

## 🤝 Συνεισφορά

Οι συνεισφορές είναι ευπρόσδεκτες! Αν έχετε μια παραδοσιακή συνταγή που θέλετε να μοιραστείτε:

### Τρόποι συνεισφοράς:

1. **Fork το project**
2. **Δημιουργήστε ένα branch** (`git checkout -b feature/new-recipe`)
3. **Προσθέστε τη συνταγή σας** στο αρχείο `index.html` στον πίνακα `recipes`
4. **Commit τις αλλαγές** (`git commit -m 'Προσθήκη συνταγής: Όνομα'`)
5. **Push στο branch** (`git push origin feature/new-recipe`)
6. **Ανοίξτε ένα Pull Request**

### Οδηγίες για προσθήκη συνταγής:

Η κάθε συνταγή ακολουθεί αυτή τη δομή:

```javascript
{
  title: "Όνομα Συνταγής",
  cat: "main" | "salad" | "dessert" | "holiday",
  img: "URL_φωτογραφίας",
  ing: [
    "Υλικό 1",
    "Υλικό 2",
    // ...
  ],
  steps: `Αναλυτικές οδηγίες εκτέλεσης...`
}
```
